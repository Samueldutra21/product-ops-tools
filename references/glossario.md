# Glossário

> **Quando ler:** ao encontrar um termo ou sigla desconhecido nesta skill.

| Termo | Significado |
|---|---|
| **ACV** | *Annual Contract Value*: valor anual de um contrato |
| **Alpha** | Problema validado e solução em construção, testada com grupo pequeno; vendas fala do problema, não promete solução |
| **APM** | *Associate Product Manager*: programa de entrada para PMs juniores |
| **ARR** | *Annual Recurring Revenue*: receita recorrente anual |
| **ASP** | *Average Selling Price*: preço médio de venda |
| **BAU / KLO / KTLO** | *Business as Usual* / *Keep the Lights On*: trabalho de manutenção da operação |
| **Baseline manual** | Primeira versão das visões de dados montada à mão para acordar o que medir antes de automatizar |
| **Beta (fechado / aberto)** | Solução validada testando escala; fechado com até cerca de 10% dos usuários cientes; aberto com mais personas; vendas pode demonstrar |
| **Bookings** | Valor de contratos fechados no período (novo, upsell, cross-sell, downsell) |
| **CAPEX / OPEX** | Despesa de capital (capitalizada e depreciada) / despesa operacional (lançada no período) |
| **Capitalização de software** | Registrar o custo de desenvolvimento como ativo e depreciá-lo na vida útil (GAAP) |
| **CKO** | *Company Kick-Off*: evento anual de estratégia para a empresa toda |
| **COGS** | *Cost of Goods Sold*: custo dos produtos e serviços vendidos |
| **Community of Practice (CoP)** | Comunidade de pessoas do mesmo papel para desenvolvimento e boas práticas (equivale a guild) |
| **Cost of Delay** | Custo de atrasar um item; base de priorização econômica |
| **Design Ops / Research Ops** | Operações que escalam design e pesquisa (padrões, repositório, acesso a usuários) |
| **Discovery (status)** | Ideia em exploração, sem validação; vendas não comenta |
| **EBITDA** | Lucro antes de juros, impostos, depreciação e amortização |
| **GA** | *Generally Available*: em produção e vendável a todos |
| **GTM** | *Go-to-Market*: lançamento e comercialização |
| **Iniciativa de produto** | Objetivo orientado a resultado que define o problema a atacar para atingir uma intenção estratégica (não é a feature) |
| **Intenção estratégica** | Desafio de negócio priorizado (no máximo 3), de 1 a 3 anos, que forma com a visão a estratégia da empresa |
| **Leading / lagging** | Indicador antecedente (prevê) / consequente (confirma) |
| **LOE** | *Level of Effort*: estimativa de esforço |
| **Manual baseline** | Ver baseline manual |
| **NPS** | *Net Promoter Score* |
| **One-pager** | Documento de iniciativa com business case e marcos (na prática, de 2 a 5 páginas) |
| **Opção** | Solução candidata para o problema de uma iniciativa, trabalhada pelos times (de 3 a 6 meses) |
| **Peanut butter** | Espalhar o time em trabalho demais, "entregando" sem valor |
| **PoP** | *Product Operations Partner*: pessoa de ProdOps embarcada e financiada por uma área |
| **Product Operating Model** | Como a empresa traduz estratégia em trabalho: papéis, processos, diretrizes cross-funcionais, governança |
| **QBR** | *Quarterly Business Review*: revisão trimestral de resultados com executivos |
| **Revenue bridge** | Decomposição da variação de receita por fonte (iniciativa, produto) |
| **SAM** | *Serviceable Addressable Market*: parcela do TAM atendível pelo alcance atual, sem considerar concorrência |
| **SDLC** | Ciclo de vida de desenvolvimento de software |
| **SOM** | *Serviceable Obtainable Market*: parcela realista do SAM, considerando concorrência, prazo e capacidade de vendas |
| **Stickiness** | DAU/MAU ou WAU/MAU: frequência de retorno |
| **SWAG** | *Scientific Wild-Ass Guess*: estimativa grosseira consciente |
| **TAM** | *Total Addressable Market*: mercado total |
| **Usefulness Assessment** | Matriz de necessidades do usuário × produtos ou features (atende, parcial, não atende) |
| **Weighted scoring** | Pontuação ponderada por critérios acordados |
| **Win/loss** | Análise dos motivos de ganho ou perda de negócios |
